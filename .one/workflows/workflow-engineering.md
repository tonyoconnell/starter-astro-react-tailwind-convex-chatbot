## Production System Setup

### Prerequisites

- Node.js 20+ installed
- Git for version control
- Pandoc for document generation (optional for advanced features)

### Installation

1. **Clone the ONE Framework**:

   ```bash
   git clone https://github.com/one-ie/playbook.git
   cd playbook
   ```

2. **Install and build the system**:

   ```bash
   npm install
   npm run build
   ```

3. **Verify installation**:

   ```bash
   npm run list:agents
   npm run validate
   npm test
   ```
