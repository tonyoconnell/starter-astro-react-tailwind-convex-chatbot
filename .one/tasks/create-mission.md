# Create Mission - Agent ONE Automated Workflow

## Purpose

Agent ONE automated mission creation workflow with comprehensive quality gate validation and CASCADE workflow integration. This task orchestrates the complete mission initialization process from user profiling through quality-validated mission generation.

## Agent ONE Mission Creation Framework

**Core Mission Creation Process:**
1. **User Profile Integration**: Leverage `one/me/me.md` for personalized mission context
2. **Company Context**: Utilize `one/company/company.md` for strategic alignment
3. **Interactive Templates**: Process `.one/templates/mission-tmpl.yaml` with elicitation
4. **Quality Gate Enforcement**: Apply `.one/tasks/mission-quality-gate.md` validation
5. **CASCADE Preparation**: Enable Mission → Story → Task → Agent progression

**Quality Standards:**
- **4.0+ Star Requirement**: No mission progresses without validated quality
- **Strategic Clarity**: Clear objectives, success metrics, and resource allocation
- **Agent Coordination**: Intelligent routing to 112+ specialized agents
- **Real-time Validation**: Automated quality gates prevent cascade failures
