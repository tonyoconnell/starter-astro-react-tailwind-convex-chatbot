## Integration Workflow

### Phase 1: Foundation Analysis
1. Use `prompts/Company.md` to extract client brand elements
2. Use `prompts/Market.md` to understand competitive context  
3. Use `prompts/Customer.md` to define target psychology
4. Synthesize foundation elements for chapter customization

### Phase 2: Industry Research Integration
1. Identify relevant industry frameworks from `playbooks/industries/[industry]/`
2. Use `prompts/DeepResearch.md` to analyze adaptation opportunities
3. Select appropriate case studies and examples
4. Map industry insights to client-specific applications

### Phase 3: Chapter Development
1. Use section-specific prompts in sequence
2. Maintain brand voice and professional standards
3. Integrate industry research with client foundation
4. Create actionable implementation guidance

### Phase 4: Quality Assurance
1. Use `prompts/BookRewriter.md` for professional polish
2. Verify brand alignment with foundation elements
3. Test implementation feasibility
4. Confirm professional-grade quality standards

## Prompt Customization Guidelines

### Client-Specific Variables
- Replace generic examples with client industry context
- Adapt language to match established brand voice
- Integrate specific competitive advantages and positioning
- Align with client's target customer psychology

### Industry-Specific Adaptations
- Use sector-appropriate terminology and examples
- Reference relevant regulations or market dynamics
- Include industry-specific tools and platforms
- Address sector-unique challenges and opportunities

### Chapter-Specific Focus
- Emphasize the specific framework being developed
- Highlight chapter-unique value propositions
- Connect to overall playbook progression
- Ensure logical flow to subsequent chapters
