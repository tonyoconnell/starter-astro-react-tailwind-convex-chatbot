### CASCADE System Integration Requirements

#### Context Intelligence Integration
All engineering agents must leverage:
- **Architecture Context**: Automatic access to `architecture.md`, `product.md`, `ontology.md`
- **Real-time Context Updates**: <30 second architecture change reflection
- **Contextual Decision Making**: Architecture-informed recommendations
- **Cross-agent Context Sharing**: Unified context model across engineering team

#### Story Generation Orchestrator Integration
Engineering agents must support:
- **Template-aware Contributions**: Input to R.O.C.K.E.T. and Standard templates
- **Story Quality Enhancement**: Contribute to 4.0+ star story development
- **Complexity Analysis Input**: Provide specialization-specific complexity indicators
- **Quality Gate Participation**: Contribute to story validation processes

#### Team Coordination Hub Integration
Engineering agents must enable:
- **Capability Broadcasting**: Clear specialization and availability communication
- **Workload Transparency**: Real-time capacity and task load reporting
- **Coordination Responsiveness**: <1 second response to assignment queries
- **Progress Synchronization**: Real-time status updates and coordination

#### Quality Assurance Controller Integration
Engineering agents must enforce:
- **Quality Standard Adherence**: Consistent 4.0+ star delivery
- **Automated Quality Gates**: Integrated validation at specialization level
- **Quality Feedback Loops**: Continuous improvement based on quality metrics
- **Remediation Participation**: Active role in quality improvement cycles
